Security Profiles Configuration

Multi-layered security profiles applied to relevant policies, powered by FortiGuard Labs.

🛡️ Security Profile Details

  • IPS Profile: High-security profile with blocking enabled for critical and high-severity vulnerabilities, accelerated by SP5 processor
  • Antivirus Profile: Protocol-based scanning for HTTP, FTP, SMTP, POP3, IMAP with malware action set to block
  • Web Filter Profile: FortiGuard category-based filtering blocking malware, phishing, adult content, and non-business categories
  • Application Control: Block P2P, proxy, and unauthorized applications; allow only business-approved SaaS
  • DNS Filter: Block resolution of malicious domains using FortiGuard DNS threat feed
  • SSL/SSH Inspection: Certificate-inspection mode for HTTPS; deep-inspection for critical servers
  • File Filter: Block executable files and dangerous file types from external sources

💡 Lessons Learned

  • Start with a "deny-all" baseline and selectively allow only necessary traffic — this is the foundation of secure firewall design.
  • Policy naming convention is critical for long-term maintainability (e.g., "Source-to-Destination-Service").
  • Regular policy audit is essential — unused rules accumulate over time and create security gaps.
  • SSL inspection can impact performance; leverage SP5 hardware acceleration and test thoroughly before enabling on high-traffic policies.
  • DMZ servers should have minimal outbound access — only allow what's absolutely necessary (DNS, updates).
  • Logging everything is important, but log rotation and storage planning must be considered early.
  • Involve application owners during policy design to understand legitimate traffic patterns.
  • Document the "why" behind each policy, not just the "what" — this helps during future audits and troubleshooting.
  • FortiGate 200F's multiple GE ports make interface planning critical — label and document port-to-zone mapping clearly.
  • Even without HA, plan for manual failover procedures and document recovery steps.
