Fortigate 200F Implementation & Network Security Optimization

Perancangan, implementasi, dan optimasi keamanan perimeter jaringan perusahaan menggunakan Fortinet Fortigate 200F untuk memastikan konektivitas yang aman, stabil, dan berkinerja tinggi.

01. Project Overview

Sebagai bagian dari upaya peningkatan keamanan siber perusahaan, saya ditugaskan untuk mengimplementasikan dan mengelola firewall Fortigate 200F. Project ini bertujuan untuk memperkuat perimeter jaringan, mengontrol lalu lintas data secara ketat, serta mengimplementasikan fitur Unified Threat Management (UTM) untuk mendeteksi dan memitigasi ancaman siber secara real-time.

02. Key Responsibilities & Implementation

  • Initial Setup & Deployment

    Melakukan instalasi fisik, konfigurasi awal (HA, Interface, VLAN), dan integrasi Fortigate 200F ke dalam infrastruktur jaringan yang sudah ada.

  • Security Policies & NAT Configuration

    Merancang dan menerapkan Firewall Policies yang ketat, termasuk konfigurasi NAT (SNAT/DNAT) dan Virtual IP (VIP) untuk mempublikasikan layanan internal secara aman.

  • Unified Threat Management (UTM)

    Mengaktifkan dan menyetel profil keamanan seperti Intrusion Prevention System (IPS), Web Filtering, Application Control, dan Antivirus untuk memblokir ancaman tingkat lanjut.

  • High Availability (HA) Setup

    Mengkonfigurasi mode Active-Passive HA untuk memastikan redundansi sistem dan meminimalkan downtime jika terjadi kegagalan perangkat.

  • VPN Configuration (IPSec & SSL)

    Membangun tunnel IPSec untuk koneksi site-to-site antar cabang, serta mengonfigurasi SSL VPN untuk akses remote karyawan yang aman.

  • Monitoring & Troubleshooting

    Melakukan monitoring log trafik, troubleshooting isu konektivitas, dan penyesuaian kebijakan keamanan berdasarkan hasil analisis ancaman.
