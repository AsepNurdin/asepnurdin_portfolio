Nextcloud Self-Hosted Collaboration Platform

Deploying a secure, self-hosted file sharing and collaboration platform as a Virtual Machine on Proxmox VE, hosted on Dell PowerEdge infrastructure to replace public cloud services.

Project Name: Enterprise File Collaboration
Author: Asep Nurdin
Role: Infrastructure Engineer
Version: 1.0

01. Project Overview

Implementing Nextcloud as a comprehensive self-hosted collaboration platform with file sharing, calendar, contacts, and real-time document editing, deployed as a VM on Proxmox VE for optimal resource utilization.

The Challenge

Reliance on public cloud services (Google Drive, Dropbox) with data sovereignty concerns, recurring subscription costs, and limited control over corporate data.

The Solution

Self-hosted Nextcloud VM deployed on Proxmox VE (hosted on Dell PowerEdge R640) with robust backup strategy, end-to-end encryption, and native user management.

The Result

Full data sovereignty, 60% cost reduction vs public cloud, enhanced collaboration tools, and complete control over data and security policies.

03. Storage Architecture

Multi-tier storage design on Proxmox host optimized for data integrity, performance, and backup reliability.

Primary Storage (ZFS Host)

Main data storage with ZFS filesystem on Proxmox host for data integrity, compression, and snapshots. 12 TB Usable

Database Storage (VM)

Dedicated virtual SSD storage for MySQL database with VirtIO drivers for high IOPS and reliability. 480 GB vDisk

Backup Storage

External NAS with daily incremental backups via Proxmox Backup Server and 90-day retention policy. 20 TB

ZFS Snapshots

Hourly VM snapshots for point-in-time recovery and ransomware protection at hypervisor level. 7-day retention

09. Security Hardening

Multi-layered security measures to protect sensitive corporate data.

  • SSL/TLS Encryption

    Let's Encrypt certificates with HSTS, TLS 1.3 enforcement.

  • Two-Factor Authentication

    Mandatory 2FA for all users (TOTP, WebAuthn).

  • Brute Force Protection

    Rate limiting, account lockout after 5 failed attempts.

  • End-to-End Encryption

    AES-256 encryption for sensitive folders.

  • Ransomware Protection

    AI-based detection, automatic file version backup.

  • File Firewall

    Block specific file types (.exe, .bat, .scr) from upload.

  • Session Management

    Auto-logout after 30 minutes idle, device management.

  • Content Security Policy

    Strict CSP headers to prevent XSS attacks.

  • ZFS Snapshots

    Hourly VM snapshots for point-in-time recovery at Proxmox level.

  • Regular Security Scans

    Automated vulnerability scanning with Nextcloud Security Scan.

11. Lessons Learned

  • VirtIO Drivers are Critical

    Using VirtIO SCSI and VirtIO Net drivers significantly improves VM disk and network performance compared to default emulated devices.

  • ZFS Snapshots at Host Level

    Schedule VM snapshots hourly at Proxmox level for quick recovery from accidental deletion or ransomware inside the VM.

  • Redis Caching is Essential

    Even for single VM deployment, Redis provides significant performance improvement for file locking and caching.

  • Native vs LDAP User Management

    Native user management works well for 100 users, but consider LDAP integration for larger scale environments.

  • Database Optimization

    Indexing and query caching are critical as file count grows beyond 10K to maintain UI responsiveness.

  • Mobile App Adoption

    Requires training — many users don't know about offline sync features and auto-upload capabilities.

  • Storage Quota Management

    Must be proactive — monitor growth trends and alert at 80% capacity to prevent storage exhaustion.

  • Collabora Online Resources

    Requires significant RAM (4GB minimum) — underprovisioning causes document save failures and timeouts.

  • Automated Maintenance

    Regular maintenance (occ:cron, file scanning, database cleanup) must be automated via system cron jobs.

  • Sync Conflict Management

    Client sync conflicts are inevitable — establish clear user guidelines for file naming and collaboration.

  • Backup Testing

    Backup testing is as important as backup itself — perform quarterly restore tests to ensure data integrity.
