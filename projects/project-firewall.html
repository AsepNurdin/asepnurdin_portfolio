Firewall Configuration & Management

Perancangan, implementasi, dan pengelolaan kebijakan keamanan jaringan menggunakan multi-vendor firewall (Fortigate, Palo Alto, Cisco) untuk memastikan konektivitas yang aman dan stabil.

01. Project Overview

Sebagai IT Infrastructure & Security Specialist, saya bertanggung jawab untuk mengelola dan mengonfigurasi firewall multi-vendor di lingkungan enterprise. Project ini mencakup implementasi kebijakan keamanan, optimasi performa, dan pemantauan ancaman secara real-time menggunakan Fortigate, Palo Alto, dan Cisco Firepower.

02. Key Responsibilities

  • Security Policy Design & Implementation

    Merancang dan menerapkan firewall policies yang ketat, termasuk konfigurasi NAT (SNAT/DNAT), Virtual IP (VIP), dan zone-based security untuk membatasi akses tidak sah.

  • Multi-Vendor Firewall Management

    Mengelola konfigurasi dan pemeliharaan firewall dari berbagai vendor (Fortigate, Palo Alto, Cisco) sesuai dengan kebutuhan dan topologi jaringan perusahaan.

  • Unified Threat Management (UTM)

    Mengaktifkan fitur keamanan lanjutan seperti IPS, Web Filtering, Application Control, dan Antivirus untuk mendeteksi dan memblokir ancaman siber.

  • VPN Configuration (IPSec & SSL)

    Membangun tunnel IPSec untuk koneksi site-to-site antar cabang, serta mengonfigurasi SSL VPN untuk akses remote karyawan yang aman.

  • High Availability (HA) Setup

    Mengkonfigurasi mode Active-Passive HA untuk memastikan redundansi sistem dan meminimalkan downtime jika terjadi kegagalan perangkat.

  • Monitoring & Troubleshooting

    Melakukan monitoring log trafik, troubleshooting isu konektivitas, dan penyesuaian kebijakan keamanan berdasarkan hasil analisis ancaman.

03. Vendor Implementations

Fortigate 200F

Implementasi utama untuk perimeter security perusahaan. Digunakan sebagai firewall utama dengan fitur UTM lengkap termasuk IPS, Web Filter, dan Application Control.

  • High Availability (Active-Passive)
  • SSL VPN & IPSec Site-to-Site
  • SD-WAN Configuration
  • FortiGuard Security Services

Palo Alto Networks

Digunakan untuk segmentasi jaringan internal dan enforcement kebijakan keamanan berbasis aplikasi (App-ID). Memberikan visibilitas mendalam terhadap traffic aplikasi.

  • App-ID & User-ID Integration
  • Zone-Based Security Policies
  • Threat Prevention & WildFire
  • GlobalProtect VPN

Cisco Firepower

Diimplementasikan untuk integrasi dengan infrastruktur Cisco yang sudah ada. Menyediakan next-generation firewall capabilities dengan manajemen terpusat melalui FMC.

  • Firepower Management Center (FMC)
  • Advanced Malware Protection (AMP)
  • Cisco Talos Intelligence
  • Integration with Cisco ISE
